# LLM 今日双预算卡片

入口：认知 → 设置 → 模型路由与预算（`cog-llm`）。卡片位于既有字段上方，其他认知分组不显示。默认 `budgetScope=global`，全局 `dailyTokenBudget=300000`，人格 `personaDailyTokenBudget=300000`；限额与模式都读取已保存配置，在下方字段编辑。

```text
┌ 今日 LLM 预算 [全局/按人格/两者取最小] ── [刷新] ┐
│ [重置全局今日] [重置当前人格今日]               │
│ 分析与回复计入两项用量；学习预算另在 cog-learning │
│ [YYYY-MM-DD UTC]                               │
│ 全局 [参与约束/仅跟踪]：所有人格共享              │
│ 已用 120       预算 500       剩余 380           │
│ 使用率 24%   ███░░░░░░░░░░░                     │
│ 当前人格 [参与约束/仅跟踪]：当前 personaId        │
│ 已用 50        预算 200       剩余 150           │
│ 使用率 25%   ███░░░░░░░░░░░                     │
│ 当前模式有效剩余：380 / 150 / 150                │
│ [提醒 / 耗尽警告 / 加载 / 错误与重试]            │
└────────────────────────────────────────────────┘
  dailyTokenBudget / budgetScope / personaDailyTokenBudget 等字段
```

| 状态 | 条件 | 展示与操作 |
| --- | --- | --- |
| 正常 | 对应行预算 > 0、使用率 < 80% | 每行已用/预算/剩余与进度，模式与 UTC 标签、有效剩余；对应行用量 > 0 可重置 |
| 接近 | 对应行使用率 ≥ 80% 且 < 100% | 每行非阻断提醒，是否约束由模式决定 |
| 行耗尽 | 对应行用量 ≥ 预算或预算 ≤ 0 | warn Banner 区分参与约束/仅跟踪，进度 100%，剩余最小 0，保留超额用量 |
| 有效耗尽 | 当前模式有效剩余 = 0 | 额外警告后续分析/回复会被预算检查阻止 |
| 加载 | 首读或刷新中 | 加载文字、aria-busy/status；统计暂隐，操作按钮禁用 |
| 错误 | GET 失败 | err Banner 与重试；两项重置禁用，刷新可用 |
| 重置中 | POST/重新读取中 | 共用忙碌锁禁用刷新和两项重置；失败 error toast，成功 toast 后 reload |

复用 `Panel`、`StatTile`、`CogBar`、`Banner`、`Btn`、`CogTag` 和 `formatCount`，沿用主题类和 token，无硬编码颜色。两行分别有 group aria-label、数值标签和进度标签；按钮提供明确范围的 aria-label，加载/状态使用 aria-live。

两项计数始终记录；模式只决定约束：global 取全局剩余，persona 取人格剩余，both 取二者最小。行标明「参与约束」或「仅跟踪」，未约束行耗尽不阻止调用。

重置需 `window.confirm` 明确全局或当前人格范围。取消不请求，确认 POST `{confirm:true,scope:'global'|'persona'}` 后 reload；API 也支持 `scope:'both'`。服务端与服务层校验 scope，日期/人格/token 等客户端字段忽略，使用服务器当前 UTC 日期及当前人格。返回双状态及 `{reset:true,removed:{global,persona}}`，幂等；无 remove 的存储降级写零。限额、模式、配置不变，不调用模型。全局重置不清除人格计数，人格重置不影响全局或其他人格，其他日期保留。

全局保留 `llm_usage`，新增人格命名空间下的 `llm_usage_persona`，移除中间实现的全局转人格迁移。旧全局数据留在原位；曾运行中间实现的旧 `persona_*:llm_usage` 与标记不自动重建/合并，以免重复计数。预算计数不参与人格复制，删除人格清除其人格计数并保留全局用量。

重置不撤销供应商费用，在途调用仍可能随后记账；请求开始时固定人格，完成时按 UTC 日期写入全局和起始人格。没有并发预算预留，可能超额；服务层预算 0 重置后仍耗尽（配置面板最小 1000）。接口细节见 [CONFIG](../CONFIG.md#llm-每日预算与今日用量)。仅离线测试，没有 live 或真实浏览器验收。
