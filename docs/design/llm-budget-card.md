# LLM 今日预算卡片

入口：认知 → 设置 → 模型路由与预算（`cog-llm`）。卡片紧邻并位于既有配置字段上方；其他认知分组不显示。预算从已保存配置读取，源码默认 `cognition.llm.dailyTokenBudget=300000`，继续用既有字段编辑。

```text
┌ 今日 LLM 预算 ─────────────── [刷新] [重置今日用量] ┐
│ 分析与回复共享预算；学习预算单独在 cog-learning     │
│ [YYYY-MM-DD UTC] [仅当前人格]                     │
│ 今日已用 token     每日预算 token    剩余 token    │
│ 120                500               380          │
│ 今日预算使用率 24%  ███░░░░░░░░░░                 │
│ [按状态显示提醒 / 警告 / 加载 / 错误与重试]        │
└──────────────────────────────────────────────────┘
  既有 dailyTokenBudget 与其他 cog-llm 配置字段
```

| 状态 | 条件 | 展示与操作 |
| --- | --- | --- |
| 正常 | 预算 > 0、使用率 < 80% | 三个 StatTile、UTC 标签、当前人格标签、进度；刷新；用量 > 0 可重置 |
| 接近 | 80% ≤ 使用率 < 100% | 非阻断提示「接近上限；仍可继续使用」 |
| 耗尽 | 用量 ≥ 预算或预算 ≤ 0 | warn Banner；进度为 100%，剩余最小 0，保留超额真实用量 |
| 加载 | 首次读取或刷新中 | 加载文字、aria-busy/status，暂不展示旧统计；操作按钮禁用 |
| 错误 | GET 失败 | err Banner 与重试；重置禁用，刷新可用 |
| 重置中 | 确认后 POST/重新读取中 | 按钮 busy，刷新/重置禁用；失败 error toast，成功 toast 后 reload |

复用 `Panel`、`StatTile`、`CogBar`、`Banner`、`Btn`、`CogTag` 和 `formatCount`。仅使用既有 `ob-panel`、`ob-stack`、`ob-row`、`ob-stat-grid`、`ob-muted`、`ob-small` 等类及其 `--ob-*` 主题 token；不新增硬编码颜色。数值文字、进度可访问标签、UTC 与人格标签提供非颜色信息，加载/状态使用 aria-live。

重置需 `window.confirm('重置今日已用 token？不会修改预算、人格或配置。')`；取消没有请求，确认发送 `{confirm:true}`，不发送日期/人格/token。服务端自行选择当前人格与 UTC 日期，删除当日记录（无 remove 的存储降级写零），幂等且不调用模型，不修改预算或配置。其他日期与人格不变，预算 0 重置后仍耗尽；重置不抵消供应商用量，执行中请求仍可稍后记账，用量归属请求开始时的人格。

旧全局 LLM 用量首次升级迁入启动时当前人格，标记 `persona.llmUsageMigration.v1` 防止重复迁移；不参与人格数据组复制，删除人格时清除。预算配置仍共享。接口与边界见 [CONFIG](../CONFIG.md#llm-每日预算与今日用量)。本设计没有 live 或真实浏览器验证证据。
